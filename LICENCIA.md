# Derechos y licencia

El código del proyecto se incluye para facilitar el control de versiones y la evaluación académica. **No se ha seleccionado una licencia de código abierto** en nombre de los autores. Antes de distribuirlo bajo MIT, GPL u otra licencia, los titulares del trabajo deben elegir y añadir el archivo `LICENSE` correspondiente. Las bibliotecas de Arduino y Python conservan sus licencias respectivas.
