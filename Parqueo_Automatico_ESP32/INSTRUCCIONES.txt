GUIA - CREAR EJECUTABLE PARA WINDOWS
===================================

1. Descarga y extrae COMPLETAMENTE este ZIP en una carpeta de Windows.
2. Asegurate de tener Python 3 instalado (comando "py -3" disponible).
3. Haz doble clic en CREAR_EJECUTABLE.cmd.
4. La primera vez se instalara PyInstaller si hace falta; necesitas Internet.
5. Espera a que finalice la compilacion.
6. El script abrira una carpeta en el Escritorio llamada:
   Parqueo_Automatico_ESP32
7. Dentro encontraras ParkingMonitorESP32.exe y la descripcion del proyecto.

PARA ABRIR EL MONITOR
- Enciende el ESP32 con el programa firmware_parqueo_ota.ino.
- El ESP32 y la PC deben estar conectados a la misma red local Wi-Fi.
- Haz doble clic en ParkingMonitorESP32.exe.
- Introduce la IP del ESP32 (anteriormente 192.168.1.18).
- Pulsa Conectar / actualizar.

PARA VERIFICAR LA API ANTES
Abre en un navegador la direccion:
http://192.168.1.18/api/estado
Si el router asigno otra IP, utiliza la nueva direccion.

SI EL ARCHIVO EXE YA EXISTIA
El script crea una carpeta nueva con un sufijo para evitar sobreescribir
el trabajo anterior.

IMPORTANTE
- La compilacion solo se puede completar y probar en Windows.
- El ejecutable resultante no requiere que Python este instalado
  para abrirse posteriormente en ese equipo.
- Los sensores todavia no estan conectados, por eso la ocupacion
  aparece como -- en la primera version.
- El firmware conserva Wi-Fi y OTA. Introduce tus propias claves
  en Arduino IDE antes de cargarlo y no las compartas.
