PROYECTO: SISTEMA DE ESTACIONAMIENTO AUTOMATICO CON ESP32
=========================================================

Nombre de la aplicacion: Parking Monitor ESP32
Tecnologias: ESP32, Wi-Fi, OTA, HTTP/JSON, Python y Tkinter.

OBJETIVO GENERAL
Desarrollar un sistema de estacionamiento automatico que permita
supervisar tres plazas y controlar una barrera de acceso, utilizando
sensores ultrasonicos, un servomotor y un microcontrolador ESP32.

FUNCIONAMIENTO PREVISTO
1. Cada plaza dispondrá de un sensor para detectar vehiculos.
2. El ESP32 calculara la cantidad de plazas ocupadas y disponibles.
3. Una pluma accionada por servomotor permitira la entrada cuando
   exista al menos una plaza disponible.
4. Cuando todas las plazas esten ocupadas, la pluma no abrira.
5. Una pantalla LCD con I2C mostrara el estado del parqueo.
6. Una aplicacion Python consultara el ESP32 por Wi-Fi y mostrara
   el estado del sistema y los mensajes registrados.

ESTADO ACTUAL: FASE 1 - COMUNICACION Y MONITOREO
- Conexion Wi-Fi del ESP32.
- Carga inalambrica de firmware por OTA.
- API HTTP con datos JSON y mensajes recientes.
- Aplicacion de escritorio Python que consulta automaticamente la API.

TODAVIA PENDIENTE
- Instalacion y calibracion de los sensores HC-SR04.
- Conexion del servomotor y la pantalla LCD I2C.
- Reglas de ocupacion, entrada y cierre seguro de la pluma.

NOTA IMPORTANTE
En esta primera fase, la capacidad total es de tres plazas, pero
las cifras de ocupacion permanecen sin determinar porque los
sensores aun no se encuentran instalados.

La aplicacion funciona dentro de la red local. No se recomienda
exponer la API del ESP32 directamente a Internet.
